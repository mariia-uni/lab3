# Аналіз виписки кредитної картки

## Опис проєкту

Цей проєкт призначений для автоматизованого аналізу даних кредитної виписки Приват Банку у форматі Excel (`.xlsx`). Програма читає історію транзакцій, зберігає їх у структурованому вигляді та дозволяє проводити базовий фінансовий аналіз за обраний період.

Основна мета проєкту — показати, як з використанням об'єктно-орієнтованого програмування та бібліотеки pandas можна працювати з таблицями Excel, зберігати дані як атрибути об'єктів і виконувати різні операції над ними.

## Кількість класів і методів

У проєкті використано 2 класи:

1. `TxnInfo`
   - відповідає за зберігання інформації про одну транзакцію;
   - містить поля для дати, категорії, номера картки, опису операції, суми, валюти та залишку.
   - має 1 класовий метод:
     - `from_row()` — створює об'єкт `TxnInfo` з рядка Excel.

2. `CreditCardStatement`
   - відповідає за всю виписку кредитної картки;
   - містить період виписки та список транзакцій.
   - має такі методи:
     - `from_excel()` — читає дані з Excel-файлу і створює об'єкт виписки;
     - `total_spent()` — підраховує загальну суму витрат;
     - `total_income()` — підраховує загальний дохід;
     - `category_spending_summary()` — агрегує витрати за категоріями;
     - `top_expense_category()` — знаходить категорію з найбільшими витратами;
     - `top_expense_merchants()` — знаходить найбільші витрати за магазинами або операціями.

Усього в проєкті використано 2 класи та 7 методів.

## Основні функції програми

Програма виконує такі функції:

- зчитування файлу Excel з історією транзакцій;
- отримання періоду виписки з таблиці;
- збереження даних транзакцій у об'єкти `TxnInfo`;
- збереження всієї виписки в об'єкт `CreditCardStatement`;
- підрахунок загальної суми витрат;
- підрахунок загального доходу;
- аналіз витрат за категоріями;
- визначення категорії з найбільшими витратами;
- визначення топових магазинів або операцій за сумою витрат;
- інтерфейс командного рядка для вибору різних варіантів аналізу.

## Технології

- Python;
- `pandas` для роботи з Excel-файлами;
- `dataclasses` для створення структур даних.

## Як запустити проєкт

1. Переконайтеся, що у вас встановлені необхідні залежності.
2. Запустіть програму командою:

```bash
python main.py
```

3. Введіть шлях до файлу `.xlsx` з історією транзакцій.
4. Оберіть потрібну дію в меню консолі.

## Приклад використання

Програма дозволяє:

- подивитися загальну суму витрат за період;
- визначити, яка категорія принесла найбільші втрати;
- побачити топ-операції за сумою витрат;
- переглянути витрати по кожній категорії;
- перевірити загальний дохід за період.

## Висновок

Цей проєкт демонструє базові принципи роботи з даними Excel у Python, використання класів і методів для моделювання реальних фінансових даних, а також спосіб організації аналітичного інтерфейсу в консолі.
